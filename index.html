Tentang saya

Dari pemrograman berbasis blok hingga membangun pengalaman interaktif dengan JavaScript.

Saya Razan Naufal Rafif, pengembang game yang antusias menggabungkan logika pemrograman dengan nilai edukasi dan budaya. Perjalanan saya dimulai dari pemrograman berbasis blok, lalu berkembang ke teknologi web dan JavaScript.

Saat ini saya menempuh pendidikan di SMA S YP UNILA dan akan melanjutkan studi S1 Teknik Informatika di Institut Teknologi Sumatera (ITERA). Saya tertarik membuat game yang seru dimainkan sekaligus punya tujuan yang bermakna.

Sergap Kartu

Digitalisasi permainan kartu tradisional Lampung untuk mengenalkan Aksara Lampung dengan cara menyenangkan. Pemain berlomba menyergap kartu sesuai aksara yang disebut, lalu menyebut urutan aksara dengan benar mengikuti aturan permainan.

Game web · JavaScript✳

Klapy Clean

Game simulasi kebersihan berbasis web dengan interaksi yang responsif. JavaScript mengelola objek sampah secara dinamis, memperbarui skor dan jumlah sampah (35/35), serta menjalankan timer satu menit untuk menentukan kondisi menang atau kalah.
